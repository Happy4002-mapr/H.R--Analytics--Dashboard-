
HR Analytics Dashboard

Project Overview
The HR Analytics Dashboard is a data visualization project developed using Microsoft Excel and Power BI. The objective of this project is to analyze employee-related data and provide meaningful insights into workforce trends, employee attrition, demographics, and organizational performance indicators.
Technologies Used

- Microsoft Excel
- Microsoft Power BI
Key Performance Indicators (KPIs)

- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate (%)
- Average Employee Age
- Average Employee Experience
Dashboard Features

- Department-wise Attrition Analysis
- Attrition Analysis by Salary Slab
- Attrition Analysis by Gender
- Attrition by Job Role and Job Satisfaction
- Age Group Distribution Analysis
- Department-wise Employee Count
- Interactive Filters and Slicers
- 
Business Objective
The purpose of this dashboard is to support Human Resource professionals in monitoring workforce metrics, identifying attrition patterns, and making informed decisions based on data-driven insights.
